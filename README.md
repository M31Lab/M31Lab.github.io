# M31Lab Website

Official website for M31Lab - Autonomous AI Agents & Cybersecurity Frameworks.

## Overview

M31Lab is a GitHub organization dedicated to developing cutting-edge autonomous AI agents, tools, and frameworks that enhance productivity and cybersecurity for modern digital ecosystems.

## Features

- 🤖 Autonomous AI Agents
- 🛡️ Cybersecurity Tools
- 🔧 Developer Tooling
- 🌐 Open Source Projects

## Tech Stack

- Next.js 13 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui
- GitHub API Integration

## Getting Started

```bash
# Clone the repository
git clone https://github.com/M31Lab/M31Lab.github.io.git

# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
